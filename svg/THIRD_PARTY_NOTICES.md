# Animated banner icons

Docker, AWS, Kubernetes, GitHub and Webpack animations are from
[TechStack Generator](https://github.com/qkrdmstlr3/techstack-generator),
by shellboy. Source SVGs were retrieved on 2026-10-23 from
`https://techstack-generator.vercel.app/{name}-icon.svg`.

The GitHub icon is displayed with an inverted color filter for contrast against
the dark banner. All five animations are embedded as inline vectors in `ngocthai.svg`.
CSS classes, IDs and keyframe names are prefixed to isolate each animation.
The standalone positioning rule on the GitHub SVG root is removed for row layout.
The AWS arrow uses orange for contrast against the dark background.
Logos and trademarks belong to their respective owners.
